# Calculadora de IMC em JavaScript

Exercício de formulário e manipulação do DOM para calcular IMC a partir de nome, peso e altura.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades e utilização

Preencha os campos respeitando as unidades indicadas e clique em Calcular.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/CalculadoraIMC-JS.git
cd CalculadoraIMC-JS
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
